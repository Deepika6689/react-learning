# React Practice Project

A simple e-commerce UI built while learning React.

## 🛠️ Tech Stack
- React
- Vite
- CSS

## 📦 Features
- Navbar
- Hero section
- Product listing with cards
- Hover effects

## 🚀 Getting Started

```bash
npm install
npm run dev
```
